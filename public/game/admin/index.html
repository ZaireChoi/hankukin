가입 회원

게임 기록 저장을 위해 로그인한 적이 있는 회원만 보여요. 가입만 하고 한 번도 접속하지 않은 계정과 비밀번호 재설정, 계정 삭제는 Firebase 화면(바로가기 탭)에서 해요.
