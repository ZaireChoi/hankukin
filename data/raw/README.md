# data/raw — 받은 원본 파일을 그대로 두는 곳

여기 있는 파일은 **손대지 않는다.** 기관이 내놓은 그대로 둔다.
가공한 결과는 `data/` 바로 아래에 JSON 으로 만들어지고, 그건 스크립트가 다시 만들 수 있다.
원본이 사라지면 다시 만들 수 없다 — 그래서 원본과 가공물을 폴더로 갈라 둔다.
