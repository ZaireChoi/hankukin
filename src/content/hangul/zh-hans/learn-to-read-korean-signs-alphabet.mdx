**你可以在大约九十分钟内学会朗读韩文。** 不是听懂，是**读出来**。而光是这一点就会改变一趟旅行 —— 因为一旦你能把招牌念出来，你就能分辨药店和诊所、面馆和烤肉店，以及你要下的那一站和下一站。

## 中文母语者的特殊处境

先说清楚，因为这决定了你该把时间花在哪。

<strong>韩文里有大量汉字词，你猜得出意思：</strong>冷面（냉면）、粉食（분식）、白饭（백반）、饭店（반점）。念出来之后，含义往往就浮现了。

<strong>但决定一家店卖什么的词，很多是固有词，汉字帮不上忙：</strong>국밥（汤饭）、칼국수（刀削面）、고깃집（烤肉店）、횟집（生鱼片店）。这些词在汉语里没有对应，只能靠读。

**所以对你来说，学会读的收益比英语母语者更高**：你不需要学会「理解」，你已经理解一半了。你只需要把另一半**念出来**。

## 为什么这么快

韩文不是像汉字那样一个字一个字记的系统。它是 1440 年代由世宗大王主持创制的**字母文字**，目的写在颁布文里 —— 让普通百姓能自己识字。

这个目的直接体现在字形上：**辅音就是嘴部动作的图示。**

## 辅音，按顺序

| | | | | |
| --- | --- | --- | --- | --- |
| **ㄱ** k/g | **ㄴ** n | **ㄷ** t/d | **ㄹ** r/l | **ㅁ** m |
| **ㅂ** p/b | **ㅅ** s | **ㅇ** 见下 | **ㅈ** ch/j | **ㅎ** h |
| **ㅋ** k' | **ㅌ** t' | **ㅍ** p' | **ㅊ** ch' | |
| **ㄲ ㄸ ㅃ ㅆ ㅉ** 紧音 | | | | |

**注意最后五个的规律：多一笔，多一口气。** ㄱ→ㅋ，ㄷ→ㅌ，ㅂ→ㅍ，ㅈ→ㅊ。把手放在嘴前念 *ga* 再念 *ka*，那一笔就是那口气。

**双写则是加紧。** ㄲ ㄸ ㅃ ㅆ ㅉ 是同样的辅音念得更紧、更硬。你现在不必发得准，只要认出 **ㄲ 就是两个 ㄱ**。

## 元音，从三笔开始

| | | | |
| --- | --- | --- | --- |
| **ㅏ** a | **ㅑ** ya | **ㅓ** eo | **ㅕ** yeo |
| **ㅗ** o | **ㅛ** yo | **ㅜ** u | **ㅠ** yu |
| **ㅡ** eu | **ㅣ** i | | |

**省下你记十个字母的规律：多一短笔就加一个 y。** ㅏ→ㅑ，ㅓ→ㅕ，ㅗ→ㅛ，ㅜ→ㅠ。右边那一整列就是这么来的。

**ㅡ 是没有对应的那个。** 嘴唇放平、舌位靠上 —— 接近汉语拼音的 e（如「个」），但更靠前、嘴不圆。韩文里到处都是，值得花两分钟。

## 一个结构性的概念：字母堆成方块

**韩文字母不是横着排的，是塞进方块音节里的。**

| 字母 | 方块 |
| --- | --- |
| ㅎ + ㅏ + ㄴ | **한** |
| ㄱ + ㅜ + ㄱ | **국** |

**元音的形状告诉你它该放哪。** 竖着的元音（ㅏ ㅓ ㅣ ㅑ ㅕ）站在辅音右边；躺着的元音（ㅗ ㅜ ㅡ ㅛ ㅠ）躺在辅音下面。收尾的辅音永远在最下面。

对读汉字长大的人来说，这一点其实很好接受 —— **方块的概念你本来就有，只是里面装的是字母而不是部件。**

## ㅇ 的规则，人人都会栽一次

**ㅇ 在方块开头时不发音。** 它是占位的，因为每个方块都必须有一个辅音位。

| 方块 | 读音 |
| --- | --- |
| **아** | a（不是 nga） |
| **어** | eo |

**ㅇ 在方块底部时读 ng。**

| 方块 | 读音 |
| --- | --- |
| **강** | gang |
| **공** | gong |

## 现在去街上试

学完上面这些，去便利店门口站三分钟。

| 招牌 | 念法 | 意思 |
| --- | --- | --- |
| **편의점** | pyeon-ui-jeom | 便利店 |
| **약국** | yak-guk | 药局（药店） |
| **카페** | ka-pe | café |
| **지하철** | ji-ha-cheol | 地下铁 |
| **출구** | chul-gu | 出口 |

**你会发现一件事：念出来之后，汉字词自己就跳出来了。** 약국 念到一半你就知道是「药局」。这就是你比英语母语者省下的那一半。

剩下的一半 —— 국밥、칼국수、고깃집 —— 需要单独认。那是另一篇文章。

## 本文没有主张的部分

**九十分钟能让你读出来，不能让你听懂。** 韩语的语法和汉语差很远，词汇也大量不重合。

**发音规则还有变化。** 韩文有一套连音与紧音化规则（比如 국밥 实际念作 [국빱]），罗马字转写完全隐藏了这一点。这些规则是有规律的，会另写一篇。
