まず料金から。お探しのものはこれのはずです。運営会社のページを2026年8月17日に読んだ時点で——

| | |
| --- | --- |
| 大人（13歳以上） | **29,000ウォン** |
| 子ども（3〜12歳） | **23,000ウォン** |
| 65歳以上 | **23,000ウォン** — 子どもと同額 |
| 36か月未満 | 無料（同伴の大人1人につき1名） |

障害者手帳による30%割引もあります。1〜3級は本人と同伴者1名、4〜6級は本人のみ。パッケージと団体は対象外。国家有功者の傷痍等級1〜3級も同じ扱いです。

この段落にひとつ注意を添えます。**韓国は2019年7月に1〜6級の障害等級制度を廃止し**、「重い／重くない」の二区分に変えました。タワーのページは今も旧等級のまま書いています。こちらでは現行制度に読み替えず、書かれているとおりに載せます——窓口が実際にどう運用しているかを確かめられていないからです。この割引が必要な方は、ページの表記と合わない手帳を持って行くより、先に電話で確かめてください。

## 英語ページが正しかったので、そう書きます

このサイトには[韓国の英語ページは韓国語ページの古い写しであることが多い](/en/now/english-pages-korea-out-of-date/)（英語）という記事があります。その証拠を探し続けるのは簡単です。ですから逆の例も、同じ日の午後に確かめた分を書いておきます。このタワーの英語の料金ページと韓国語の料金ページは**同じ二つの数字**を載せており、営業時間の表も、レストラン一軒ずつまで一行も違いませんでした。

両方を最新に保っている韓国の事業者がいるなら、それは一文の価値があります。

## 公式サイトが二つ、会社も二つ

ここで多くの人が違う場所に着きます。

タワーを検索すると **seoultower.co.kr** が出てきます。公式サイトです。ただし展望台のものではありません。いまは **YTN서울타워** と名乗り、建物、広場、店舗、南山を登る道を扱っていて——**チケットのページがひとつもありません。**「N서울타워」はそのサイトのナビゲーションの中で *매장안내*（テナント案内）の下にあります。

展望台には自分のサイト **nseoultower.co.kr** があり、上の料金はそこに載っています。誰が運営しているかは、こちらが読んだページには書かれていませんでした。いちばん強い手がかりは、エラーページの問い合わせ先が **cj.net** のアドレスだということ。細い糸であり、細いと申し添えます。確かなのは、**二つのドメインに二つのブランドがあり、料金を教えてくれるのは片方だけ**ということです。

つまりこのタワーは、空に見えるシルエットは一つで、書類の上では会社が二つあります。[遺失物センターが4か所・運営会社が3社に分かれている](/ja/now/lost-something-in-korea-what-to-do/)のと同じ形です。どちらも隠されてはいません。ただ、説明もされていません。

## 営業時間と、人を落とす30分

年中無休。韓国語の時刻表から、英語版と一致した内容です。

| | 平日 | 土日・祝 |
| --- | --- | --- |
| **展望台** | 10:00〜22:30 | 10:00〜23:00 |
| Nギフトショップ（プラザ5F） | 10:00〜22:00 | 10:00〜22:00 |
| n.GRILL | 12:00〜22:00 | 12:00〜22:00 |
| THE PLACE DINING | 11:00〜22:00 | 11:00〜22:00 |
| Nテラス | 11:00〜20:00 | 11:00〜20:00 |

**最終入場は閉館の30分前** — つまり**平日は22:00、土日・祝は22:30**です。両方の言語版に書かれていて、夜の予定を壊すのはこの一行です。火曜の22:20、建物はまだ明るく、人がいて、食事も出ています。そして展望台はもう人を入れていません。

同じページからもう二つ。営業時間は「weather conditions and operating schedules（天候と運営日程）」で変わるとあります。どの天候かは書かれていないので、こちらで名指しはしません。ただ、上の表は予定であって約束ではない、ということです。そして5階の展望フロアは回ります。Tower data ページには **View 5F** に149m²の回転区域があり、一周に**1時間40分**とあります。気づかない程度に遅く、腰を下ろしたときの背景のままではない程度に速い。なお、これはギフトショップの5階とは別の5階です——あちらはプラザ5F、もう一方の会社の建物です。

## 窓口で買うか、行く前に買うか

**公式サイトはチケットを売っていません。** 提携先へ送るだけで、英語トップページには Trip.com と韓国観光公社のサイトが並んでいます。つまり「運営会社から直接オンラインで買う」は、ここでは選択肢に入っていません。探し始める前に知っておく価値があります。

きょう開いた Klook では、展望台の単品が **US$14.19**（定価表示 US$20.50）、ケーブルカーのパッケージが **US$26.75**、ファストトラックが **US$38.89** と出ていました。通貨は各販売者が表示したまま書き、換算はしません。レートは動きますし、実際に請求される額は決済時に選ぶ通貨で変わるからです。

**読むべきは割引率ではなく条件です** — しかもその条件はページの中で一律ではありません。だからページ単位ではなく、商品ごとに書きます。

上の三つ——展望台単品、ケーブルカーパッケージ、ファストトラック——はいずれも**取消不可・返金不可・日付変更不可**で、**2026年12月31日まで有効**のオープンチケットです。混雑で入場できなかった場合は、返金ではなく別の日に使ってくださいと案内されます。同じページのコンボ2種は違います。選んだ日付限定と表示され、そのうち祭りのチケットは24時間前までの無料取消がついています。**実際に買う商品のバッジを読んでください。**

値段が隠している実務がひとつ。ケーブルカーのパッケージは**スマホのチケットではありません。** 上がる前に明洞で実物のチケットを受け取ります。ホテルを出てそのままケーブルカーに乗るつもりだったなら、寄り道が要ります。

前もって買うほうが窓口より得か——それは書きません。**それは通貨換算であり、換算はしないと申し上げたばかりです。** こちらが言えるのは、その晩が流れたときに各選択肢がいくらになるか、です。窓口なら、ゼロです。

## 上がり方

四通りあり、それを整理しているのは*もう一方*のサイト——YTN側です。徒歩、ケーブルカー、公共交通、車。

以下は**運営会社ではなく Klook の掲載内容**なので、時刻表ではなく一販売者の説明として読んでください。多くの人が使うのは**南山循環バス01番**。忠武路駅（3・4号線）か東国大学駅（3号線）から乗り、6〜9分間隔、06:30〜23:00の運行。ケーブルカーは明洞駅3番出口を出て、南山3号トンネルの案内に従い、**10〜15分ほど歩いて**南山オルムのリフトへ。そこからケーブルカー乗り場に上がります。この徒歩の部分を、多くの人が予定に入れていません。

n.GRILL での食事について、Klook のページは電話が必要だと書いています——**02-3455-9297 / 9298**。Klook のパッケージに含まれるものがないためです。推測させるより先に断っておく点が二つ。オンライン予約の経路はこちらでは見つけられませんでした（無いという意味ではありません）。そして同じページはこの番号を遺失物の連絡先としても挙げているので、レストラン専用というよりタワーの代表番号に見えます。

## この記事が主張しないこと

**上がっていません。** 上に書いたことはすべて、2026年8月17日に運営会社の公開ページと一販売者の掲載内容から読んだものです。行列も、眺めも、ファストトラックが料金分の時間を節約するかも、確かめていません。

**ケーブルカーの運営会社と料金は調べていません。** タワーとは別の事業者で、そのページは読んでいません。

**ソウルスカイや63とは比べていません。** きょうはそれらのページがこちらから開かず、三つのうち一つだけで作った比較は、比較しないより悪いからです。

**展望台を誰が運営しているかは確認できていません。** 上記のとおり、エラーページのメールアドレスは手がかりであって登記ではありません。

**400mは運営会社の数字であり、実測ではありません。** Tower data の表ではなく展望台ページの文章に出てくる数字で、二つのページの間で整合は取られていません。こちらはどちらかを選ばず、両方を引きました。
