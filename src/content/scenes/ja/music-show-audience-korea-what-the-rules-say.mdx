音楽番組の観覧について書かれたものは、驚くほど内容が揃っています。公式サイトから申し込む。パスポートを持って行く。早めに着く。どれも正しい。

ただ、実際に人を止める条件はどこにも出てきません。それはKBSの申込ページに韓国語で書いてあります。**ミュージックバンクは一席では取れません。二席単位で、二人とも歩いて入らなければならない。**

## 名前は最初に二つ、あとから差し替えはきかない

同伴者の名前は、申し込むその瞬間に入力します。あとからでも、当日でもありません。

ページはそのあと、思いつきそうな抜け道も塞いでいます。友人の名前で予約して一人で行くことはできません。当日は二人とも指定の時間に到着し、本人確認を受けてからでないと、どちらも入れないと書かれています。しかも本人確認は現物の身分証で、コピーや写真は受け付けないと明記されています。

つまり一人旅の人が抽選に当たっても、席を手に入れたことにはなりません。**使えない席を二つ手に入れただけ**です。

これは旅程を組む前に知っておくことで、あとから知ることではありません。そして友人と行った人が書いた案内には、まず出てこない種類の条件です。

## KBSの残りの条件を、引っかかる順に

以下はすべて同じページにあり、2026年8月18日に読んだものです。

| | |
| --- | --- |
| **申込開始** | 放送の一週間前の木曜 09:00 |
| **申込締切** | 同じ週の金曜 24:00 |
| **当選発表** | 月曜18:00以降に申込ページ／木曜14:00以降にショートメッセージ |
| **座席** | ランダムに割り当て。座席番号は当選発表と一緒に出る |
| **年齢** | 15歳未満は、チケットの有無にかかわらず入場不可 |
| **当日** | 14:00から入場券の引き換え、入場は16:10〜16:40 |
| **生放送が始まったら** | 入場不可 |

このうち二行は、韓国に住んでいる人より旅行者に重くのしかかります。

**当選連絡はショートメッセージで届きます。** 申込ページとKBSのアプリのモバイルチケットという別の経路もあるので、韓国の番号が絶対に必要というわけではありません。それでも多くの人が頼るのはSMSで、海外から準備している段階なら、これは[韓国の番号を前提にしている仕組み](/ja/decode/korea-esim-no-phone-number/)がまた一つ増えたということです。

**入場は16:40で閉まりますが、放送の開始はそのあとです。** ミュージックバンクは2026年7月10日から金曜17:15に移りました（番組のお知らせ欄より）。この差は余裕ではありません。放送前に扉が閉まるということです。

案内から抜け落ちがちな条件がもう二つあります。スタジオ内での撮影・録音は禁止で、見つかった場合は記録の削除と退場になるとページに書かれています。そして観覧そのものが同意です。客席は撮影され、その映像が放送とオンラインで使われることに、参加した時点で同意したものとみなす、と明記されています。韓国のテレビに映りたくない人は、この段落を二度読んでください。

## SBSは案内を「画像」で出していた

人気歌謡にも観覧のページがあります。同じような一覧を想定して開きました。

返ってきたのは、見出しだけで本文が何もない画面でした。最初は、SBSがページを空のまま置いているのだと読みました。

そこで画面を撮ってみたら、案内はちゃんとそこにありました。手順を説明する縦長のピンクの図です。**このページは画像一枚でできています。** 案内の中に、選択できる文字は一文字もありません。

これは細かい話ではありません。文字でできたページは、ブラウザが翻訳でき、検索が拾い、読み上げソフトが読み、翻訳アプリに貼り付けられます。画像一枚のページは、画像を読む別の道具を持ち出さないかぎり、そのどれもできません。外国のファンにとって、SBSの案内は韓国語で書かれているのではありません。**何語でもない状態**です。

私たちは[韓国のサイトの外国語ページは韓国語ページの古い写しである、という記事](/en/now/english-pages-korea-out-of-date/)（英語）を出しています。これはその一段下です。ここには古くなる外国語ページすらありません。翻訳する文字が最初から存在しないからです。

## その画像に何が書いてあるか

「読めなかった」で終わらせないために、画面を撮って目で読みました。

経路はウェブページではなく放送局のアプリです。**SBS play → マイ → 観覧および申込履歴 → 観覧申込のバナー**、そこから日付を選びます。当選はアプリのプッシュ通知で届き、入場はアプリの中のチケットで行います。

筋の通った仕組みですし、すでにその中にいる人にとってはKBSより滑らかでしょう。ただしその入口は、韓国の放送局のアプリを入れてアカウントを作るところから始まります。**外国のパスポートを持ち韓国に住所がない人が、そのアカウント作成で何を求められるのかは確認できていません。** 後述します。

画像の中から一つ記録しておきます。手順の説明に使われている端末画面には、人気歌謡の第1244回から1247回、入場日は2024年11月までが写っています。番組はすでに第1320回を越えました。この案内の図は、作られてから描き直されていません。

## 無料のはずのものを売る人たち

両局のサイトで一番強い文章は、申込ページにはありません。ミュージックバンクのお知らせ欄にあり、KBSはそれを二度書きました。韓国語で一度、英語でもう一度。

KBSはこの告知に英語版も並べており、そこでは「外国のK-POPファンを狙った犯罪である」とはっきり書いています。**どの言語を選んだかが、誰に向けた告知かを示しています。**

告知は注意喚起にとどまりません。観覧券を利益目的で売る行為は違法であること、取引が確認されたチケットは入場を断ること、そして金銭的な被害の責任は取引した当事者にあることが書かれています。申込ページ側にも同じ規定が逆から書かれています。重複予約と、チケットの売買・譲渡が発覚した場合、予約は無効になり入場できません。

さらにKBSは、他の放送局では見たことのないことをしています。告知と並べて、ある収録日に取引が摘発された申込者二名を、氏名とIDを部分的に伏せた形で公開しているのです。

申込ページには、どの段階にも価格の記載も支払いの手順もありません。放送局自身がこのチケットの売買を犯罪と呼んでいることと合わせて読めば、形ははっきりしています。**ミュージックバンクの席に金が動くこと自体が危険信号**であって、取引の中身の問題ではありません。

## 確認できなかったこと、そして推測しないこと

**外国のパスポートで申込が完了するかどうか。** どちらの経路も放送局のアカウントが必要で、私たちはそれを作っていません。二次的な情報源には、KBSにはパスポートで登録できる経路があり、SBSは外国人登録証を求める、という記述があります。どちらも一次資料で確認できていません。SBSの条件は画像の中にあり、アカウントの画面はログインの向こう側だからです。自分の目で見るまでは、どちらも事実として書きません。

**旅行会社が売っている有料の観覧パッケージが、KBSの言う不正取引にあたるかどうか。** 人気歌謡のパッケージを旅行会社から買うことを勧める記事がいくつもあります。それらの会社に私たちの知らない取り決めがあるのかもしれませんし、ないのかもしれません。違法だとも、安全だとも言いません。言えるのは狭いことだけです。KBSの告知は、ミュージックバンクの観覧券を利益目的で売るのは違法であり、取引されたチケットは入口で断られる、と書いています。どちらかの番組の席に誰かへ金を払おうとしているなら、支払う前にその一文を売り手に示してください。

**SBSの案内画像が、私たちが読んだあとで変わっていないかどうか。** 画像は文字のように差分を取れません。2026年8月18日に何が写っていたかを記録しました。あとから読む人は、自分で開いて見てください。

## この記事が主張していないこと

扱っているのはKBSのミュージックバンクとSBSの人気歌謡の二番組だけです。MBC、Mnet、MBC Mその他の音楽番組については何も述べていません。そちらの規定はここの規定ではありません。

上に書いたことはすべて2026年8月18日に読んだもので、その日の内容です。申込の期間、入場の時刻、年齢の制限は、放送局が大きく告知せずに変える種類のものです。日付は約束ではなく形として受け取り、頼りにする前にページを開いてください。

私たちはどちらの収録にも行っていませんし、申し込んでもいませんし、どちらの放送局にもアカウントを持っていません。この記事が伝えているのは二つのページに何が書いてあったかであって、入口で何が起きるかではありません。
