关于去看韩国打歌舞台的攻略，内容一致得出奇。从官网申请。带上护照。早点到。这些都没错。

我们读过的攻略里，没有一篇提到真正会把你挡住的那条。它就写在KBS自己的申请页上，用的是韩文：**《音乐银行》不是一个座位一个座位放的。它一次放两个，而且两个人都得走进来。**

## 名字要在一开始就写两个，之后不能换

同行者的姓名是在你提交申请的那一刻填的。不是之后，也不是当天。

这一页接着把最容易想到的绕路也堵上了。带着朋友的名字一个人去是不行的：页面写明当天两个人都要在规定时间到场、通过本人核验之后，才有人能进去。而核验要的是证件原件——复印件和照片都不接受。

也就是说，一个人出行的人即使中签，也没有拿到座位。**他拿到的是两个用不了的座位。**

这是排行程之前该知道的事，不是事后才知道的事。而且这种条件，在一个和朋友同行的人写的攻略里通常不会出现。

## KBS其余的条件，按会卡住你的顺序

以下都在同一页上，读于2026年8月18日。

| | |
| --- | --- |
| **申请开始** | 播出前一周的周四 09:00 |
| **申请截止** | 同一周的周五 24:00 |
| **公布结果** | 周一18:00起在申请页查看；周四14:00起发送短信 |
| **座位** | 随机分配，座位号随结果一起公布 |
| **年龄** | 未满15岁不得入场，有票也不行 |
| **当天** | 14:00起换取入场券，入场时间16:10–16:40 |
| **直播开始后** | 不得入场 |

其中两行对旅行者的分量，比对本地人重得多。

**结果是用短信通知的。** 还有另一条路——申请页面，以及KBS自家应用里的电子票——所以并非非有韩国号码不可。但多数人依赖的还是短信；如果你正在国外做计划，这不过是[又一个默认你有韩国手机号的系统](/zh-hans/decode/korea-esim-no-phone-number/)。

**入场16:40关闭，而节目在这之后才开始。**《音乐银行》从2026年7月10日起改到周五17:15播出（见节目公告栏）。这段时间差不是余量，是门在开播之前就关上了。

还有两条攻略常略过的规定。演播室内禁止拍照和录音，页面写明一旦被发现，材料要删除、人要请出去。而且到场本身就是同意：观众席会被拍进画面，页面写明参与观看即视为同意这些画面用于播出和网络。如果你不希望自己出现在韩国电视上，这一段值得读两遍。

## SBS把说明做成了一张图

《人气歌谣》也有观众页。我们本以为会看到一份类似的清单。

页面回来的是：一个标题，然后什么都没有。我们最初的判断是，SBS把这一页留空了。

然后我们截了屏，说明就在那儿——一张竖长的粉色图，把整个流程画了出来。**这一页就是一张图片。** 说明里没有一个可以选中的字。

这个区别不是咬文嚼字。由文字构成的页面，浏览器能翻译、搜索引擎能收录、读屏软件能朗读、也能复制到翻译软件里。由一张图片构成的页面，除非另外动用能读图的工具，否则这些一个都做不到。对外国粉丝来说，SBS的说明不是"用韩文写的"。**它不是用任何语言写的。**

我们写过[一篇文章，说韩国网站的外语页往往是韩文页的旧版本](/en/now/english-pages-korea-out-of-date/)（英文）。这里比那还低一层。这里连一个会过期的外语页都没有，因为一开始就没有可供翻译的文字。

## 那张图上写了什么

为了不停在"这页读不了"，我们把屏幕截下来，用眼睛读了一遍。

路径不是网页而是电视台的应用：**SBS play → 我的 → 观看及申请记录 → 观众申请横幅**，然后选日期。结果通过应用推送送达，入场用应用里的电子票。

这套流程本身是通的，对已经身处其中的人来说，大概比KBS那套还顺。但它的入口是：装一个韩国电视台的应用，并在里面注册账号。**持外国护照、在韩国没有住址的人在注册时会被要求什么，我们没能验证。** 下文会说明。

图里有一个细节值得记下来。用来演示步骤的手机截图，显示的是《人气歌谣》第1244至1247期，入场日期到2024年11月为止。节目现在已经过了第1320期。这张说明图自制作以来没有重画过。

## 本该免费的东西，有人在卖

两家电视台网站上分量最重的一段话，不在申请页上。它在《音乐银行》的公告栏里，而且KBS写了两遍——一遍韩文，一遍英文。

KBS在同一则公告里并列放了英文版，其中直接写道：这是"针对外国K-POP粉丝的犯罪"。**它选择用哪种语言，本身就说明了这则公告是写给谁看的。**

公告不止于提醒。它写明：以营利为目的出售这些券是违法的；被认定参与交易的票将被拒绝入场；由此产生的经济损失由交易双方自负。申请页从另一个方向写了同一条规定：重复预约以及任何形式的转卖或转让，都会导致预约作废、无法入场。

KBS还做了一件我们在别处没见过的事。在公告旁边，它把某个录制日被查获交易的两名申请者公开了出来，姓名和账号做了部分遮盖。

申请页从头到尾没有出现价格，也没有任何付款步骤。把这一点和"电视台自己把出售这种券称为犯罪"放在一起读，事情的形状就清楚了：**为《音乐银行》的一个座位付钱这件事本身就是警讯**，而不是某笔交易的细节问题。

## 我们没能核实的，以及不会去猜的

**两边的申请能不能用外国护照走完。** 两条路径都需要电视台的账号，而我们没有注册。二手资料称KBS有基于护照的注册通道、SBS要求外国人登录证。这两点我们都无法在一手页面上确认——SBS的条件在图片里，账号页面在登录之后。在亲眼看到之前，我们不会把其中任何一条当作事实复述。

**旅行社在卖的付费观演套餐，是不是KBS所说的非法交易。** 有好几篇攻略推荐向旅行公司购买《人气歌谣》套餐。这些公司可能有我们不知道的安排，也可能没有。我们不说它们违法，也不说它们安全。我们能说的只有很窄的一句：KBS自己的公告写着，以营利为目的出售《音乐银行》观众券是违法的，且被认定交易过的票会在门口被拒。如果你正打算为其中任何一个节目的座位付钱给谁，付款之前请把那句话拿给卖方看。

**SBS的说明图在我们读过之后有没有变。** 图片没法像文字那样做差异比对。我们记录的是它在2026年8月18日显示的内容；之后来读的人，请自己打开看一眼。
